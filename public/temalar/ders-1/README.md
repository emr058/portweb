# Ders Takvimi

Statik tema demosu, kurs ve özel eğitim programı için haftalık çizelge düzeni.

## Açma

`index.html` dosyasını tarayıcıda açın. Harici servis, paket kurulum adımı veya arka uç yoktur. Yazı tipleri ve beş eğitim arşivi fotoğrafı yerel dosyalardır.

## Düzenleme

- `index.html`: marka adı, örnek program satırları, ders açıklamaları, soru-cevap ve görsel kredileri.
- `style.css`: renk, ölçü ve responsive yerleşim.
- `app.js`: haftanın günlerine göre örnek program süzgeci.
- `assets/credits.json`: arşiv görsellerinin kaynak ve lisans kaydı.

Programdaki tüm dersler demo içeriğidir. Gerçek ders, eğitmen, saat, yaş aralığı, mekân ve iletişim bilgileri eklenmelidir. Temanın canlı etkileşimi gün filtresidir; JavaScript devre dışıyken tüm satırlar görünür kalır.
