# Tarih Kartelası

Düğün ve organizasyon işletmeleri için bağımsız, çevrimdışı çalışabilen statik demo tema.

## Çalıştırma

Bu klasörde `python3 -m http.server 8000` çalıştırıp `http://localhost:8000` adresini açın. Derleme, bağımlılık kurulumu, API veya uzak servis gerekmez.

## Demo sınırı

Gerçek işletme adı, telefon/WhatsApp, e-posta, adres, mekân, paket, fiyat ve kurulum akışı sağlanmadı. Etkinlik türleri ve akış metinleri örnek kabul edilmelidir. Form yalnızca tarayıcıda bir özet üretir; veri göndermez veya saklamaz. Yayın öncesinde işletmenin gerçek iletişim kanalı eklenmelidir.

## Kaynaklar

- Yazı tipi: Jost, SIL Open Font License 1.1; lisans `fonts/OFL.txt` içinde.
- `assets/` içindeki dört çizim bu tema için SVG ile oluşturulmuştur. Gerçek etkinlik fotoğrafı değildir.
- Fotoğraf kredisi yoktur; hiçbir temadan fotoğraf kopyalanmamıştır.
